# Doris 目标表管理

通过 Integrate 应用门户进入“数据中台”，打开 **数据集成 → 目标表管理**。页面读取已启用 Doris 目标数据源中的真实表；需要先在“数据源管理”维护 Doris 目标连接。只有治理管理员可以设计表和修改结构。

## 新建目标表

1. 选择 Doris 目标连接，点击“新建目标表”。右侧抽屉会固定显示目标数据库，不需要先选择来源表。
2. 填写表名、表说明和分桶数；表名与字段名使用字母、数字、下划线，首字符为字母或下划线。
3. 添加字段，选择字段类型、主键及是否允许空值。展开“字段配置”，设置长度、精度、小数位、默认值和字段说明。可以复制、删除草稿字段及调整顺序。
4. 选择一个非空主键。当前设计器创建单主键 `UNIQUE KEY` 表，以支持主键合并更新；主键不能使用 FLOAT、DOUBLE 或 STRING。分布方式为按主键 HASH，副本数由环境配置控制。
5. 点击“预览建表”，核对服务端生成的字段结构与只读 SQL，再确认创建。预览之后修改配置，需要重新预览。

支持 BIGINT、INT、SMALLINT、TINYINT、DECIMAL、VARCHAR、CHAR、STRING、DATE、DATETIME、BOOLEAN、FLOAT 和 DOUBLE。VARCHAR 长度为 1–65533 字节，CHAR 为 1–255 字节；DECIMAL 总精度为 1–38，小数位不能超过总精度；DATETIME 小数秒为 0–6 位。单表最多 128 个字段。

默认值可以选择不设置、NULL、固定值，或适用于对应日期类型的当前日期/当前时间。固定值会按字段类型校验，不接受任意 SQL 表达式。新增非空字段必须提供非空默认值。

任务抽屉中也有“新建目标表”入口。已选来源表或已解析 SQL 结果时，可以从来源结构填充字段，再手动调整。导入前已修改的字段会要求确认覆盖；表名和表说明会保留。

## 给已有表新增字段

在目标表列表点击“新增字段”。抽屉可展开查看现有真实结构，新增的字段单独编辑。预览后提交 `ADD COLUMN`，保留现有主键、字段和数据。

- 当前仅支持向原生 Doris UNIQUE 表追加字段；不提供删除已有字段、改名、改类型或替换主键。
- 新增字段名不能和现有字段重复，现有字段加新增字段不能超过 128 个。
- 非空新字段必须配置非空默认值，便于已有行取得该字段的值。
- Doris 结构变更可能异步完成。抽屉会刷新真实结构并核对字段定义；提交超时或响应丢失时，先刷新结构核实结果，避免重复提交。
- 有活动同步任务、待确认提交或未完成结构变更时，服务端拒绝再次改表。先等待终态，再重新读取和预览。

当前活动任务保护按同名数据库和表保守拦截 Doris 连接，以覆盖不同 FE、DNS 和端口别名。若多个独立 Doris 集群使用相同库表名，可能需要先等待另一个集群的同名任务结束。

## 用于集成任务

建表完成后，列表的“用于新建任务”会打开集成任务抽屉，预选实际目标连接、数据库和表。在任务内建表时，结果会直接回填当前任务，并保留其他已填写配置。

选择来源表或 SQL 结果，检查主键和字段映射，校验后保存。来源字段可映射到现有目标字段，未映射且允许为空或有默认值的目标字段由 Doris 填充。全量、SQL T+1 和历史初始化继续使用既有任务流程。

## 配置及故障处理

设计器使用已保存的数据源凭据从 K8s 服务端连接 Doris，不会把密码放到浏览器里。写入账号需要目标数据库内的 SELECT、LOAD、CREATE 和 ALTER 权限；设计器不需要 DROP 或管理员权限。测试环境只对隔离库 `ods_validation` 追加 ALTER_PRIV。

预览指纹绑定连接版本和实际目标结构。其他操作更改表结构或连接配置后，旧预览会被拒绝，应重新读取并预览。服务端只执行由结构化字段生成的受限 DDL，浏览器中的 SQL 预览不可编辑。

当前固定 Doris 4.0.8 的字段注释解析器会移除反斜杠，因此字段注释不接受 `\`，路径说明请用 `/`。表注释及字符串默认值中的引号、反斜杠已单独按该版本原生解析行为处理。
